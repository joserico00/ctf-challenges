# Scripting / Programming

Twelve short "run it and fix it" Python challenges (`python/pass01.py` to `python/pass12.py`) that I wrote for students with no programming background. Each program prints its flag once it runs and its logic is correct.

| Script | Concept |
|---|---|
| `pass01.py` | Running a script |
| `pass02.py` | Booleans and `if`/`else` |
| `pass03.py` | `while` loops and variable initialization |
| `pass04.py` | List indexing and loop bounds |
| `pass05.py` | Variables and output |
| `pass06.py` | `for` loops and `range()` |
| `pass07.py` | `getpass` and hardcoded secrets in source |
| `pass08.py` | String methods (`replace`, `rstrip`) |
| `pass09.py` | Boolean conditions |
| `pass10.py` | Program flow around `random.randint` |
| `pass11.py` | `datetime` comparisons |
| `pass12.py` | Syntax errors and type mismatches |

All levels are Easy, except `pass12.py` (Easy-Medium). The flags live in the source by design, so treat these as practice challenges.

The flags in the scripts are placeholders (`cybercamp{your_flag_here}`, or `CTF{your_flag_here}` in `pass07.py`), so set your own before an event. Keep each level's mechanics when you do: `pass04.py` and `pass06.py` spell the flag as a list of characters or parts, and `pass08.py` pads it with extra `1`s that players have to strip. See the [main README](../README.md) for more.
