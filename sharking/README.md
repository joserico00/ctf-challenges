# Sharking (network forensics)

A Wireshark-themed challenge folder with artifacts that appear to be objects exported from web traffic.

| File | Description |
|---|---|
| `shark.jpg`, `shark(1).jpg`, `shark(2).jpg`, `shark(3).jpg` | Pieces of image data. None starts with a JPEG header, so they won't open as images on their own. |

- **Skill:** HTTP object export in Wireshark, file-signature (magic byte) analysis, reconstructing data from exported objects
- **Difficulty:** Medium
- No capture file or build script is included.

Solutions are intentionally not included. See the [main README](../README.md).
