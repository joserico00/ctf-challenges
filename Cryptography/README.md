# Cryptography

Ten static encoding and cipher challenges I built for beginner workshops. Each file contains a single flag-formatted message run through one scheme. There are no build scripts; the files are the challenges.

| Folder | Concept | Difficulty |
|---|---|---|
| `A1Z26/` | Letter-to-number substitution | Easy |
| `Caesar/` | Caesar / ROT-N shift cipher | Easy |
| `ascii/` | Decimal ASCII code points | Easy |
| `decimal/` | Decimal ASCII code points (second variant) | Easy |
| `binarytext/` | 7-bit binary ASCII | Easy |
| `base64/` | Base64 | Easy |
| `bacon/` | Baconian cipher | Easy-Medium |
| `morse_code/` | Morse code | Easy |
| `vigenere/` | Vigenère cipher, with a key hint in `info.txt` (Spanish) | Easy-Medium |
| `hash/` | Hash identification and recovering the input | Medium |

Solutions are intentionally not included. See the [main README](../README.md) for details on every challenge.
