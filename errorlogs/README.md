# Error log analysis

| File | Purpose |
|---|---|
| `err.py` | Build script: writes `error_log.txt` with 1,000 lines chosen at random from 10 message templates, one of which is the flag |

- **Player gets:** `error_log.txt`, a noisy simulated server error log. It is generated by `err.py` and not committed.
- **Skill:** log triage with `sort | uniq -c`, `grep` and `grep -v`
- **Difficulty:** Easy
- **Build:** set your own flag in the `error_messages` list in `err.py` (it ships with a placeholder), then run `python3 err.py` in this folder. It creates or overwrites `error_log.txt`. Change the `range(1000)` loop count to adjust the log length.

Give players only the generated `error_log.txt`, not `err.py`. See the [main README](../README.md).
